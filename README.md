# resipoc-privacy

Static landing site for the Resipoc privacy policy. Served via GitHub Pages.

The privacy policy URL is what gets entered into:

- App Store Connect → App Privacy → Privacy Policy URL
- Google Play Console → Store presence → Main store listing → Privacy policy URL

The single page (`index.html`) is canonical. To update, edit it directly and push — Pages will redeploy automatically.

This repo intentionally contains no code, no analytics, no tracking. The privacy policy itself declares the app collects no personal data; this site is consistent with that promise.
